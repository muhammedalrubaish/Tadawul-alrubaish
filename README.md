# رصد — مساعد قرار التداول

تطبيق ويب عربي (PWA) للسوقين السعودي (تداول) والأمريكي: أسعار حقيقية، رادار فرص، محاكي تاريخي، مختبر استراتيجيات، بوت تيليجرام، مساعد ذكي (DeepSeek أو Claude)، وتداول آلي للسوق الأمريكي عبر Alpaca يقرر فيه الذكاء الاصطناعي ضمن حدود صارمة.

## البنية
- `index.html` — الواجهة كاملة (بلا إطار عمل).
- `api/` — دوال Vercel. الملفات المبدوءة بـ`_` وحدات مشتركة لا تُكشف كنقاط نهاية.
- الأسعار: Yahoo Finance أساساً، مع احتياطي SAHMK (سعودي) وTwelve Data (أمريكي).

## متغيرات البيئة (Vercel → Settings → Environment Variables)

| المتغير | الغرض | الافتراضي |
|---|---|---|
| `DEEPSEEK_API_KEY` | مفتاح DeepSeek (الأرخص) للمساعد وقرارات التداول | — |
| `DEEPSEEK_MODEL` | نموذج DeepSeek | `deepseek-chat` |
| `ANTHROPIC_API_KEY` | مفتاح Claude (بديل) | — |
| `AI_PROVIDER` | `deepseek` أو `anthropic` — يُحدَّد تلقائياً حسب المفتاح المضبوط، وClaude أولاً إن وُجد الاثنان | تلقائي |
| `AI_MODEL` | نموذج Claude | `claude-opus-5` |
| `AI_EFFORT` / `AI_TRADE_EFFORT` | جهد Claude للمساعد / لقرارات التداول | `low` / `high` |
| `AI_PASS` | رمز يحمي المساعد في الموقع من الغرباء | — |
| `TELEGRAM_TOKEN` / `TELEGRAM_CHAT` | بوت تيليجرام (مطلوبان للوكيل المجدول) | — |
| `CRON_SECRET` | حماية `/api/agent` (يرسله Vercel تلقائياً للكرون) — اضبطه دائماً | — |
| `ALPACA_KEY` / `ALPACA_SECRET` | مفاتيح وسيط Alpaca | — |
| `ALPACA_PAPER` | `false` = حساب حقيقي | `true` (تجريبي) |
| `AUTOTRADE_ENABLED` | المفتاح الرئيسي للتنفيذ الفعلي | `false` |
| `AUTOTRADE_MODE` | `ai` يقرر الذكاء الاصطناعي · `rules` معادلة الدرجة فقط | `ai` إن وُجد مفتاح ذكاء اصطناعي |
| `AUTOTRADE_MAX_POSITION_USD` | أقصى قيمة للصفقة الواحدة | `200` |
| `AUTOTRADE_MAX_OPEN_POSITIONS` | أقصى عدد مراكز مفتوحة (تشمل أوامر الشراء المعلّقة) | `5` |
| `AUTOTRADE_MAX_DAILY_TRADES` | أقصى صفقات شراء في اليوم | `3` |
| `AUTOTRADE_DAILY_LOSS_LIMIT_USD` | قاطع دائرة: لا شراء بعد خسارة يومية تتجاوزه | `100` |
| `AUTOTRADE_MAX_SLIPPAGE_PCT` | أمر الدخول بحد سعري = آخر سعر × (1 + هذه النسبة) | `1` |
| `AUTOTRADE_AI_MIN_CONFIDENCE` | لا يُنفَّذ قرار شراء بثقة أقل | `70` |
| `AUTOTRADE_AI_POOL_SCORE` / `AUTOTRADE_AI_POOL_SIZE` | عتبة الدرجة وحجم قائمة المرشّحين المعروضة على النموذج | `50` / `25` |
| `AUTOTRADE_AI_CAN_SELL` | السماح للنموذج بإغلاق مركز قائم | `false` |
| `AUTOTRADE_MIN_SCORE` | وضع `rules`: عتبة الشراء | `72` |

## كيف يعمل التداول الآلي
1. الكرون يستدعي `/api/agent` قبل افتتاح وول ستريت (13:00 UTC).
2. يفحص الوسيط: الحساب غير موقوف، السوق يفتح اليوم، الخسارة اليومية دون الحد، عدد المراكز والصفقات دون الحدود. تُلغى أوامر شراء قديمة لم تُنفَّذ.
3. وضع `ai`: تُعرض على النموذج قائمة المرشّحين (درجة ≥ 50) مع المراكز المفتوحة والحساب والحدود، ويعيد قرارات JSON (شراء/تجاهل/إغلاق) مع وقف وهدف وسبب. Claude ملزم ببنية الـJSON من الخادم؛ DeepSeek يُطلب منه JSON فقط، لذا يُفحص كل حقل في الكود ويُسقط أي قرار ناقص أو بنوع خاطئ. يُنفَّذ الشراء فقط بثقة ≥ 70، والوقف يُقيَّد بين 2–8٪ والهدف بين 3–20٪ وبنسبة ≥ 1.5× الوقف.
4. يُرسل أمر شراء بحد سعري (لا مطاردة للفجوات) من نوع bracket بصلاحية GTC: الوقف والهدف يُنفَّذهما الوسيط حتى لو تعطّل الخادم.
5. النتيجة والأسباب تصل إلى تيليجرام، وتظهر الصفقات (المفتوحة بوقفها وهدفها، والمعلّقة، والمغلقة بربحها) في قسم «صفقات الوكيل» بصفحة «محفظتي» — يتطلب `AI_PASS` لأن بيانات الحساب حساسة.

أوامر البوت: «فرص» · رمز سهم · «حالة التداول» · «رأي الوكيل» (معاينة بلا تنفيذ) · «تداول الآن» · «أوقف الكل».

معاينة يدوية بلا تنفيذ: `/api/agent?market=us&dry=1&key=<CRON_SECRET>` (أضف `&notify=1` لإرسالها إلى تيليجرام).

> أداة شخصية تعليمية وليست توصية استثمارية. ابدأ دائماً بالحساب التجريبي.
